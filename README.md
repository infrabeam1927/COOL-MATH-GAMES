# Math Games Arcade 🕹️

A browser-based mini-game arcade with 6 classic games, built entirely in vanilla HTML, CSS, and JavaScript — no build step, no dependencies, no external scripts.

**[▶ Play Live on GitHub Pages](https://infrabeam1927.github.io/COOL-MATH-GAMES/)**

---

## Games

| Game | Description |
|------|-------------|
| **2048** | Slide tiles on a 4×4 grid and merge numbers until you hit 2048. Arrow keys + swipe support. |
| **Snake** | Guide the snake to eat food and grow longer on a 20×20 grid. Speeds up as you grow. |
| **Memory Match** | Flip pairs of emoji cards in a 4×4 grid with the fewest moves possible. |
| **Math Sprint** | Solve rapid-fire arithmetic problems (add, subtract, multiply) in 60 seconds. |
| **Tic-Tac-Toe** | Play against the CPU. Toggle Easy / Hard — Hard mode uses minimax and is unbeatable. |
| **Breakout** | Classic brick breaker. Clear all bricks to advance to the next level. 3 lives. |

## Features

- Dark neon arcade theme with a distinct accent color per game
- Best scores persisted in `localStorage`
- Fully responsive — works on desktop and mobile/touch
- Single `index.html` file, zero dependencies

## Running Locally

Just open `index.html` in any modern browser.
